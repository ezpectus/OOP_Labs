# Лабораторна робота №5

## Розробка багатовіконного інтерфейсу користувача для графічного редактора об'єктів

**Мета:** отримати вміння та навички програмувати багатовіконний інтерфейс
програми в об'єктно-орієнтованому стилі.

## Варіанти та вимоги

1. Номер варіанту = номеру у журналі.
   - **Непарні (1, 3, 5, ...)** — глобальний статичний об'єкт MyEditor
     у вигляді **Singleton Меєрса** (`static MyEditor instance;` у getInstance()).
   - Парні — класичний Singleton.
2. Кольори/стилі фігур — як у лаб. №4.
3. **Вікно таблиці** — окремий пункт меню для відкриття/закриття;
   автоматично закривається при виході. Формат (Табл. 5.1):
   `Назва | x1 | y1 | x2 | y2`.
4. Вікно таблиці = **немодальне діалогове вікно**, таблиця — клас
   в окремому модулі (наприклад `MyTable`).
5. **Запис файлу** множини об'єктів — CSV з 5 полями: тип + x1,y1,x2,y2.
6. Ієрархія/модулі — зручні для додавання нових типів без переписування
   існуючих модулів.
7. У звіті — діаграма класів.

## Бонуси (підвищують оцінку)

1. Виділення рядка таблиці → відповідний об'єкт виділяється на канвасі.
2. Виділення рядка таблиці → об'єкт вилучається з масиву.
3. Завантаження CSV → відновлення об'єктів у вікні та таблиці.

Для бонусів 1–2 **заборонено** нові залежності модуля my_table від інших
файлів — повідомлення клієнту через **Callback / Observer / Listener**.
