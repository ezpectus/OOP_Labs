# Лабораторна робота №4

## Вдосконалення структури коду графічного редактора об'єктів

**Мета:** отримати вміння та навички проектування класів, виконавши
модернізацію коду графічного редактора в об'єктно-орієнтованому стилі для
забезпечення зручного додавання нових типів об'єктів.

## Завдання

1. Створити у середовищі розробки проект з ім'ям Lab4.
2. Написати вихідний текст програми згідно варіанту завдання.
3. Скомпілювати вихідний текст і отримати виконуваний файл програми.
4. Перевірити роботу програми. Налагодити програму.
5. Проаналізувати та прокоментувати результати та вихідний текст програми.
6. Оформити звіт.

## Варіанти завдань та основні вимоги

1. Номер варіанту = номеру у списку студентів у журналі.
   - **Непарні (1, 3, 5, ...)** — глобальний **статичний** об'єкт класу MyEditor.
   - Парні — динамічний об'єкт MyEditor (коректне створення/знищення).
2. Усі кольори та стилі геометричних форм — як у лаб. №3,
   **крім «гумового» сліду**: при вводі усіх фігур — **пунктирна** лінія.
3. Окрім чотирьох типів фігур з лаб. №2/№3, додати **два нових**:
   **лінія з кружечками** та **каркас куба**. Кольори — на розсуд.
   Класи нових фігур — саме **множинним успадкуванням**:
   - LineCircles: `Show` з LineShape (лінія) + `Show` з EllipseShape (кружечки)
   - Cube: `Show` з LineShape (ребра) + `Show` з RectShape (грані)
4. Для усіх **шести** типів фігур — кнопки Toolbar з підказками (tooltips).
5. У звіті — **діаграма класів** (схема успадкування).

## Зміст звіту

Титул → варіант → сорси (головний .cpp фрагменти + модулі) →
діаграма класів → скріншоти → висновки.
