### Теоретичні положення

Програмна система будується як множина незалежно працюючих програмних компонентів, які взаємодіють через обмін повідомленнями. Це відображає архітектуру об'єктно-орієнтованих систем, де об'єкти взаємодіють шляхом надсилання та отримання повідомлень.

#### Пошук об'єкта-компонента для співпраці

Для надсилання повідомлення вікну іншої програми потрібно знати `hWnd` її вікна. Функція `FindWindow` дозволяє отримати `hWnd` будь-якої працюючої програми за іменем класу її вікна:

```cpp
HWND hWndOther = FindWindow(L"DATACREATOR", nullptr);
if (hWndOther)
    SendMessage(hWndOther, WM_USER + 1, 0, 0);
```

#### Запуск програми іншою програмою

Функція `WinExec` викликає іншу програму:

```cpp
WinExec("otherprog.exe myfile.txt 3471", SW_SHOW);
```

У командному рядку можна передати параметри, наприклад `hWnd` вікна програми-ініціатора, щоб викликана програма могла надіслати відповідь.

#### Передавання даних між програмами

**1. SendMessage / PostMessage** — для передачі одного числа:
```cpp
PostMessage(hWndOther, WM_USER + 1, someValue, 0);
```

**2. WM_COPYDATA** — для передачі масиву даних між програмами:
```cpp
typedef struct {
    DWORD dwData;      // одне числове значення
    DWORD cbData;      // розмір даних
    PVOID lpData;      // вказівник на дані
} COPYDATASTRUCT;

// Відправка
COPYDATASTRUCT cds;
int data[5] = {1, 2, 3, 4, 5};
cds.dwData = 0;
cds.cbData = sizeof(data);
cds.lpData = data;
SendMessage(hWndOther, WM_COPYDATA, (WPARAM)hWnd, (LPARAM)&cds);

// Прийом
void OnCopyData(HWND hWnd, WPARAM wParam, LPARAM lParam) {
    COPYDATASTRUCT* cds = (COPYDATASTRUCT*)lParam;
    long* p = (long*)cds->lpData;
    int nPoints = p[0];
    int xMin = p[1];
    // ...
}
```

**Важливо:** дані, що передаються через `WM_COPYDATA`, не можуть містити вказівники або посилання на об'єкти, недоступні для іншої програми. Вказівник `lpData` дійсний тільки під час обробки повідомлення. Дані тільки для читання.

**3. Clipboard Windows** — для обміну текстовими даними між програмами:
```cpp
// Запис у Clipboard
HGLOBAL hglb = GlobalAlloc(GMEM_MOVEABLE, size);
memcpy(GlobalLock(hglb), data, size);
GlobalUnlock(hglb);
OpenClipboard(hWnd);
EmptyClipboard();
SetClipboardData(CF_TEXT, hglb);
CloseClipboard();

// Читання з Clipboard
OpenClipboard(hWnd);
HGLOBAL hglb = GetClipboardData(CF_TEXT);
char* text = (char*)GlobalLock(hglb);
// обробка text
GlobalUnlock(hglb);
CloseClipboard();
```

#### Формат повідомлення

Повідомлення повинно містити:
- тип повідомлення (команда, запит даних, сповіщення про подію)
- ідентифікатор відправника
- ідентифікатор отримувача (або широкомовне)
- дані (параметри повідомлення)

#### Вимоги щодо організації системи

- Компоненти повинні бути слабко зв'язаними (loose coupling)
- Компоненти не повинні знати внутрішню реалізацію один одного
- Взаємодія виключно через інтерфейс повідомлень
- Можливість додавання нових компонентів без зміни існуючих
