# Лабораторна робота №6

## Тема: Програмна система з компонентами для обробки даних

### Мета

Одержання практичних навичок створення програмних систем, що складаються
з кількох незалежних програм-компонентів, які обмінюються даними через
механізми Windows API.

### Порядок виконання

1. Створити у середовищі MS Visual Studio C++ проєкт Win32 з ім'ям Lab6.
2. Написати вихідний текст програми згідно варіанту завдання.
3. Скомпілювати вихідний текст і отримати виконуваний файл програми.
4. Перевірити роботу програми. Налагодити програму.
5. Проаналізувати та прокоментувати результати та вихідний текст програми.

### Варіант (Ж = 13, Ж mod 4 = 1)

Три незалежні програми, що обмінюються даними через `WM_COPYDATA`
та Clipboard:

- **Lab6 (Менеджер)** — користувач вводить параметри: `n`, `Min`, `Max`.
  Менеджер запускає Object2 та Object3 через `WinExec`, розташовує вікна
  на екрані, передає параметри через `WM_COPYDATA`.
- **Object2 (Генератор матриці)** — створює матрицю `n×n` цілих чисел
  у діапазоні Min–Max, відображає її у вікні, записує дані у Clipboard
  (`CF_TEXT`: перший рядок — `n`, далі `n` рядків tab-separated),
  повідомляє Object3 через `PostMessage(WM_USER+100)`.
- **Object3 (Детермінант)** — читає матрицю з Clipboard, обчислює
  детермінант методом Гауса (частковий вибір головного елемента)
  та відображає значення `det(A)` у вікні.

Усі три програми — повністю незалежні: жодних спільних `.h` файлів,
зв'язок лише через `WM_COPYDATA`, Clipboard та `PostMessage`.
