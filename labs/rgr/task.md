# РГР — Варіант 13 (Ж = 13)

## Тема

**Програма списку студентів групи з розрахунками успішності.**

## Завдання

Розробити програму для ведення списку студентів академічної групи
з розрахунками успішності. Програма має забезпечувати:

- додавання, редагування та видалення студентів;
- відображення списку групи у вигляді таблиці;
- сортування списку (за середнім балом, за прізвищем);
- розрахунок показників успішності:
  - середній бал кожного студента;
  - середній бал групи;
  - відсоток успішності;
  - кількість відмінників та боржників;
- збереження та завантаження списку з файлу.

## Реалізація

- `class Student` — ПІБ, № залікової книжки, 5 оцінок, `avg()`,
  `hasDebt()`, `isExcellent()`;
- `class StudentGroup` — `vector<Student>`, add/edit/remove,
  сортування, статистика групи, save/load CSV;
- UI — Win32: головне вікно з `ListView`, меню, модальні діалоги
  Add/Edit та статистики.
